Displays a yearly, monthly, weekly or daily archive of posts for one or more specific categories.

== Description ==

Displays a archive of posts for one or more specific categories in the Gutenberg block editor. It can be configured to group by year, month, week or day with post counts and as a listing or a pulldown.

= Features =
* Option multi category selection
* Option group by year, month, week or day
* Option to either show a listing or a pulldown, with an optional label
* Option show post counts
* Option to show the date in the archive page title
* Option to order
* Option for alignment, spacing, color, typography and border
* Transform from the core Archives block

== Frequently Asked Questions ==

= How is the Category Archives Block different than the built-in Archive widget? =

The Category Archives Block lets you show posts for one or more specific categories.  The built-in Archive widget shows posts for all categories. The Category Archives Block can also show the date in the title of the archive page and sort the archive from oldest to newest.

= How do I replace an existing core Archives block? =

Select the Archives block, click the block icon in the toolbar and transform it to "Category Archives". Grouping, dropdown, label, post counts and styles are kept. Then choose the categories in the block settings.

= Which page opens when a visitor clicks an archive link? =

The date archive of your theme, filtered to the selected categories (e.g. /2026/05/?cat=3,7). You can change its layout in the Site Editor with the "Date Archives" or "All Archives" template.

= Can the result page show which year, month or day is displayed? =

Yes. Select at least one category, then enable "Show date in archive title" in the block settings. The archive page title shows the date (e.g. "Month: May 2026") instead of the category.
